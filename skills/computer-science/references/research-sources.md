# Research sources and current guidance

Load this reference when giving advice about computer-science education, language standards, or tooling whose behavior may change. Prefer the primary source for the particular language, platform, or standard instead of treating this list as an exhaustive authority.

## Computing education

- **ACM/IEEE-CS Computer Science Curricula 2023** — https://csed.acm.org/ — use its competency-oriented curriculum guidance when discussing postsecondary computer-science learning outcomes.
- **CSTA K–12 Computer Science Standards** — https://csteachers.org/k12standards — use for age-appropriate K–12 concepts and progression; do not assume a standard applies to every local curriculum.

## Algorithms and programming languages

- **MIT OpenCourseWare, Introduction to Algorithms** — https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/ — use for foundational algorithm analysis and examples; still derive the complexity claim for the user's concrete code.
- **ISO C++ working draft** — https://eel.is/c++draft/ — consult when a C++ language-rule claim needs current normative wording.
- **Python documentation** — https://docs.python.org/3/ — consult for Python version-specific behavior rather than relying on remembered implementation details.

## Verification practice

When providing code or a complexity bound, state assumptions, test representative and boundary inputs, and separate asymptotic complexity from measured performance. For current APIs, compiler behavior, package versions, or platform limits, link the applicable official documentation and identify the version or date checked.
