## Scope and method

This Gate 9 audit applies the repository workflow's skill-appropriate diagnostic lenses to `SKILL.md` and its directly routed references. It evaluates instructions rather than factual city guidance.

| Lens | Finding | Result |
|---|---|---|
| Lens 2: Positive vs Negative | The entry point uses positive source-selection instructions rather than prohibition-heavy stop markers. | No instruction rewrite required. |
| Lens 3: Consistency | Topic routing, state declaration, and current-information handling are compatible. | No conflicting operational instruction found. |
| Lens 4: Anchoring precision | Each high-fragility topic identifies the reference and requires a linked official source before a volatile claim is quoted. | Concrete routing retained. |
| Lens 6: Working-space hygiene | The entry point has one context-selection sequence, one source-freshness check, and direct topic paths. Detailed guidance stays in references. | Core concept load remains below the workflow threshold. |

## Positive execution rules retained

- Load `research-sources.md` before quoting a time-sensitive fare, visa threshold, registration rule, or legal permission.
- State planning estimates as estimates and use the linked official source for a live value.
- Select the user's context before loading a topic reference.
