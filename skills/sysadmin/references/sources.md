# Sources

Use the operating system's version-matched documentation as the authority for commands and defaults.

## Service management and logs

- systemd: https://www.freedesktop.org/software/systemd/man/latest/systemctl.html — service lifecycle commands.
- systemd journal: https://www.freedesktop.org/software/systemd/man/latest/journalctl.html — journal filtering and follow mode.

## Accounts, permissions, and storage

- Linux manual pages, `useradd(8)`: https://man7.org/linux/man-pages/man8/useradd.8.html — system-account options vary by distribution.
- Linux manual pages, `mount(8)`: https://man7.org/linux/man-pages/man8/mount.8.html — mount options and filesystem handling.
- Linux manual pages, `chmod(1)`: https://man7.org/linux/man-pages/man1/chmod.1.html — permission mode semantics.

## Package and backup operations

- Debian APT user guide: https://www.debian.org/doc/manuals/apt-guide/ — package index and upgrade workflow.
- CISA ransomware guide: https://www.cisa.gov/stopransomware/ransomware-guide — resilient, tested backups and recovery planning.
