# Monetization strategy

- Select subscriptions, one-time purchases, consumables, ads, or a hybrid model based on the recurring value delivered and the platform rules.
- Place a paywall after a user has encountered the relevant value. State price, billing period, renewal terms, and cancellation path clearly.
- Test trial length, price, packaging, and paywall timing with a predeclared success metric; avoid changing several variables in one experiment.
- Track conversion, refunds, churn, renewal, ARPU, and cohort LTV. Evaluate LTV and CAC with consistent attribution and time windows.
- Do not use dark patterns, forced consent, or misleading scarcity to improve conversion.
