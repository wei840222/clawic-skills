# Grammar and Sentence Shape

Use `は` for established topic or contrast and `が` for new, exhaustive, or relative-clause subjects: `誰が来ましたか → 田中さんが来ました`; then `田中さんは営業です`. Drop a subject once it is recoverable.

Check transitive/intransitive pairs (`ドアが開く` / `ドアを開ける`) and keep one tense/aspect logic. Prefer a sentence with one main idea. When a modifier before a noun becomes long, split it: state the event first, then name the noun. Replace translated scaffolding (`〜における`, `〜に関して`, `〜を通じて`) with the simpler Japanese relation when possible.
