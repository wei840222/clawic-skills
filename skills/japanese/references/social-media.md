# Social and Creator Platforms

Decide the platform before the prose. LINE and X reward brevity; note articles need an informative title and a clear opening; Instagram and TikTok need an immediate visual or emotional hook; YouTube descriptions should make the topic searchable without keyword stuffing.

Do not invent first-hand experience, results, prices, locations, sponsorships, or audience reactions. Use placeholders for missing facts. Keep hashtags, calls to action, and emoji only when the user asks or the platform/context clearly calls for them.
