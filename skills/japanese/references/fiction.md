# Fiction, Dialogue, and Localization

Set each speaker's first person, address form, sentence endings, and register before drafting dialogue. Narrative prose may use 常体 while dialogue follows character voice; that is not accidental register mixing. Keep character limits, UI context, and genre conventions visible for games and subtitles.

Role language (`ですわ`, `じゃ`, etc.) is a convention, not a neutral default. Use it only when the requested genre and character support it, and avoid stereotyping dialect, gender, age, or social class. Preserve variables and markup exactly in localization strings.
