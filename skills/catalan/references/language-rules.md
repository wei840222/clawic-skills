# Catalan language rules and regional checks

Load this reference when a task needs a region-specific result, a formal register, or a grammar review beyond the core guidance.

## Dialect and register

- Central Catalan is a practical neutral default for general audiences.
- For Valencian, use the requested local vocabulary consistently; `vesprada` is a common choice where Central Catalan uses `tarda`.
- Balearic varieties have distinctive articles and verb forms. Use these only when the user requests the variety or the audience clearly calls for it.
- Formality depends on the relationship and setting. `vostè` is a formal option, not an age-based rule.

## Grammar checks

- Use weak pronouns (`en`, `hi`, and others) according to the verb and referent; do not copy Spanish object-pronoun patterns.
- Use `per` for cause, means, exchange, route, and duration; use `per a` for a recipient, purpose, or destination when the distinction is required by the selected register.
- Possessives normally take an article: `el meu`, `la teva`.

## Authentic vocabulary

Prefer Catalan equivalents where they convey the intended meaning: `aleshores` or `llavors` (not `entonces`), `gairebé` (not `casi`), `a prop` (not `cerca`), `escombraries` (not `basura`), and `feines` or `tasques` (not `tareas`). Preserve a user's quoted wording when translating or explaining it.
