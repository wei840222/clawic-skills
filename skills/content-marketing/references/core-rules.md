# Content planning checks

Apply these checks before finalizing a strategy or calendar:

1. **Funnel fit:** identify awareness, consideration, or decision intent and one appropriate next action.
2. **Audience fit:** state the audience problem, proof, and value exchange before choosing a format.
3. **Calendar integrity:** record publication date, owner, status, funnel stage, distribution channels, and measurement window in `<state_root>/calendar.md` only after consent.
4. **Voice consistency:** retain approved tone, terminology, and examples in `<state_root>/memory.md`; use the current brief when no saved voice exists.
5. **Distribution plan:** define channel-specific derivatives and an owner before publication.
6. **Measurement:** track the metric that represents the selected next action, alongside reach or engagement context.
7. **Content bank:** keep validated ideas, audience questions, and learning in `<state_root>/content-bank/` only when persistent storage is enabled.

## Recovery branches

- If the audience, objective, or offer is unknown, produce a short discovery brief and label assumptions instead of inventing a full calendar.
- If analytics are unavailable, define the required event, metric, owner, and review date; keep performance conclusions pending.
- If a source asset cannot be reused because of rights, privacy, or approval constraints, create a new brief rather than republishing it.
