# Sources

Domain anchors used while hardening `friend`. Prefer primary guidance over secondary summaries.

## Companion presence and listening

- **Active Listening (Wikipedia)** — core behaviors: attending, reflecting, clarifying, summarizing without premature advice via https://en.wikipedia.org/wiki/Active_listening
- **Motivational Interviewing Network of Trainers (MINT) — Understanding MI** — evoke the person's own reasons; resist fixing reflex via https://motivationalinterviewing.org/understanding-motivational-interviewing
- **APA Dictionary — empathy** — understanding another's experience while keeping self-other distinction via https://dictionary.apa.org/empathy

## Boundaries, dual relationships, and non-substitution

- **APA Ethical Principles of Psychologists and Code of Conduct** — beneficence, nonmaleficence, and limits of dual/helping roles (informational only; this skill is not therapy) via https://www.apa.org/ethics/code
- **SAMHSA — Finding Quality Treatment for Substance Use Disorders** — route people toward real-world care rather than AI-only support via https://www.samhsa.gov/find-help/helplines
- **World Health Organization — Mental health** — professional care and community supports remain primary for mental health needs via https://www.who.int/health-topics/mental-health

## Crisis escalation (non-clinical companion limits)

- **IASP — Find a crisis centre** — country-indexed local crisis resources via https://www.iasp.info/suicidalthoughts/
- **988 Suicide & Crisis Lifeline (US)** — call/text/chat 988 overview via https://www.988lifeline.org/
- **International Association for Suicide Prevention — resources** — global pointers and guidance framing via https://www.iasp.info/resources/

## Feedback without enabling

- **Nonviolent Communication (CNVC overview)** — observations vs evaluations; care before critique via https://www.cnvc.org/learn-nvc/what-is-nvc
- **Gottman Institute — The Four Horsemen** — criticism/contempt patterns to avoid when giving hard feedback via https://www.gottman.com/blog/the-four-horsemen-recognizing-criticism-contempt-defensiveness-and-stonewalling/
