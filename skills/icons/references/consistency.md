# Consistency

- Stick to one icon set per product surface — mixing stroke styles looks unfinished.
- Match icon stroke weight to nearby font weight (regular UI text ≈ 1.5px at 24px).
- Pick one treatment per state family: outlined for idle, filled for active/selected when the set supports both.
- Optical alignment differs from mathematical centering — circles reach the viewBox edge; squares often need optical inset.
- Name icons by appearance, not overloaded meaning: `stopwatch` not `speed`, `trash` not `delete-item-forever`.
- Keep viewBox and optical padding consistent so adjacent icons share a visual baseline.
