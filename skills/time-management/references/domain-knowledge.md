# Time Management Domain Knowledge

Load this file when explaining why a method works or when the user asks for sources. Prefer the planning rules in `SKILL.md` and the method files over dumping this page into every reply.

## Time blocking and deep work

Time blocking divides the day into named clock ranges dedicated to a task or task group, replacing an open-ended to-do list with a structured timeline. Deep-work practice pairs those blocks with uninterrupted focus on cognitively demanding work.

- Cal Newport, *Deep Work* — book overview and practice framing via https://www.calnewport.com/books/deep-work/
- Francesco Cirillo, The Pomodoro Technique — short focused intervals with deliberate breaks via https://francescocirillo.com/pages/pomodoro-technique

## Prioritization methods

### Eisenhower Matrix

Prioritize by urgency and importance into Do / Schedule / Delegate / Delete so important non-urgent work is not crowded out by noise.

- FranklinCovey overview of the time matrix rooted in Covey’s *The 7 Habits of Highly Effective People* via https://www.franklincovey.com/the-7-habits/

### Eat the frog

Start with the hardest or highest-leverage task while peak energy is available, then move to lighter work.

- Brian Tracy, *Eat That Frog!* summary guidance via https://www.briantracy.com/blog/time-management/the-truth-about-frogs/

## Weekly reviews and open loops

A weekly review collects loose ends, reviews active commitments, and resets priorities so the next week’s blocks match real goals rather than leftover urgency.

- David Allen / Getting Things Done — official GTD overview via https://gettingthingsdone.com/what-is-gtd/

## Energy and meeting load

Protect contiguous morning focus when the user controls the calendar; when meetings are externally imposed, plan MITs into the longest remaining quiet windows and batch communication instead of reacting continuously.

- CDC / NIOSH work-hour module on circadian performance and recovery needs via https://www.cdc.gov/niosh/work-hour-training-for-nurses/longhours/mod2/08.html
